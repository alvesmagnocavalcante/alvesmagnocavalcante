### Projeto em destaque

**[Ongma — Automation Orchestration](https://github.com/alvesmagnocavalcante/gerenciador)**

Plataforma para gerenciar, agendar, executar e monitorar automações Python e RPAs.

- Execução local ou distribuída com Ongma Agent em Go.
- Integração com repositórios Git.
- Agendamento por Cron e intervalos.
- Gerenciamento de dependências com uv.
- Monitoramento de execuções e logs em tempo real.
- RunTrail para rastreamento das etapas de execução.
- Distribuição via Docker Compose e GHCR.
