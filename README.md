### Projeto em destaque

**[Ongma — Automation Orchestration](https://github.com/alvesmagnocavalcante/gerenciador)**

Plataforma para cadastrar, agendar, executar e monitorar automações Python e RPAs em um só lugar.

| Recurso | Descrição |
|---|---|
| Execução | Local ou distribuída, com o **Ongma Agent** escrito em Go |
| Código | Integração direta com repositórios Git |
| Agendamento | Cron e intervalos |
| Dependências | Ambientes isolados gerenciados com uv |
| Observabilidade | Status das execuções e logs em tempo real |
| Rastreamento | **RunTrail** para acompanhar cada etapa de uma execução |
| Distribuição | Docker Compose e imagens no GHCR |
